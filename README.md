# インディー実況週報

個人開発ゲームの実況おすすめサイトです。
`admin.html`（編集室）からゲームを追加・修正・削除すると、GitHub Pages の本番サイトに 1〜2 分で反映されます。

## ファイルの中身

| ファイル | 役割 |
|---|---|
| `index.html` | 公開されるサイト本体 |
| `admin.html` | ゲームを登録・修正・削除する編集室 |
| `games.json` | ゲームの一覧データ（編集室が自動で書き換えます） |
| `card.js` / `style.css` | カードの見た目（サイトと編集室で共通） |
| `images/` | 編集室からアップロードした画像が入ります |

## はじめの準備（最初の1回だけ）

### 1. リポジトリを作る
1. GitHub 右上の「＋」→「New repository」
2. 名前を決める（例：`jikkyo-weekly`）
3. **Public** を選んで「Create repository」

### 2. ファイルをアップロードする
1. 作ったリポジトリで「Add file」→「Upload files」
2. このフォルダの中身を **フォルダごとではなく中身を全部** ドラッグ＆ドロップ（`images` フォルダも含めて）
3. 「Commit changes」

### 3. サイトを公開する
1. リポジトリの「Settings」→ 左メニュー「Pages」
2. Source を「Deploy from a branch」、Branch を「main」「/ (root)」にして「Save」
3. 数分後、`https://ユーザー名.github.io/リポジトリ名/` でサイトが見られます

### 4. 編集室用のトークン（合言葉）を作る
1. GitHub 右上のアイコン →「Settings」→ 左メニューの一番下「Developer settings」
2. 「Personal access tokens」→「Fine-grained tokens」→「Generate new token」
3. 設定する内容
   - Token name：`jikkyo-admin` など
   - Expiration：90日 など（期限が切れたら作り直します）
   - Repository access：**Only select repositories** → このサイトのリポジトリだけ選ぶ
   - Permissions → Repository permissions → **Contents：Read and write**
4. 「Generate token」を押して、表示された `github_pat_…` をコピー
   （この画面を閉じると二度と表示されないので注意）

> トークンは**誰にも見せず、どのファイルにも書かないでください**。
> このサイトのリポジトリだけに権限を絞っているので、万が一のときも他には影響しません。
> 心配なときは同じ画面からすぐ削除（Revoke）できます。

## 編集室の使い方

1. `https://ユーザー名.github.io/リポジトリ名/admin.html` を開く
2. 「接続の設定」にユーザー名・リポジトリ名・トークンを入れて「接続して読み込む」
3. 「このパソコンに記憶する」にチェックしておけば、次からは開くだけで自動接続されます

| やりたいこと | 操作 |
|---|---|
| 追加 | 「＋ 新しく追加」→ フォームに入力 →「追加してサイトに反映」 |
| 修正 | 左の一覧からゲームを選ぶ → 直す →「修正してサイトに反映」 |
| 削除 | 左の一覧からゲームを選ぶ →「このゲームを削除」 |
| 週の名前を変える | 上の欄に入力 →「週の名前を反映」 |

- 右側の「サイトでの見え方」で、公開後の見た目を確認しながら入力できます
- 画像は横 1280px までに自動で縮めてからアップロードされます
- 画像を差し替えたり削除したりすると、古い画像も自動で消えます
- 反映には 1〜2 分かかります。変わらないときはページを再読み込みしてください
- 最初に入っている【見本】のゲームは、編集室から削除してください

## サムネイルの優先順位

1. 作者さんに許可をもらった画像、またはプレスキットで使用が許可されている画像（編集室でアップロード）
2. Steam のアプリID → Steam 公式の紹介枠
3. itch.io のゲームID → itch.io 公式の埋め込み
4. どれもなければ、タイトルの1文字目とジャンルの色で作ったカード

## 検索の言い換えを増やす

`index.html` の中の `SYNONYMS` に1行足すと、その言葉でも検索に引っかかるようになります。

```js
"ゆるい":["まったり","癒し"],
```
